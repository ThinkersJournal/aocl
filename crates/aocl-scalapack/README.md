# aocl-scalapack

Safe Rust wrappers for AOCL-ScaLAPACK — distributed linear algebra over MPI.

**Wrappers written; every wrapper (`Grid`, `BlockCyclic`, all `pd*`, `ps*`, `pcgesv`, `pzgesv`) is exercised on 1-6 MPI ranks, including 2D grids up to 2x3, three right-hand sides and a non-zero grid origin (`tests/grid2d_mpi.rs`). The `ilp64` feature does not work (32-bit declarations) and is refused at compile time.** ScaLAPACK ships only Fortran-style symbols (no public C headers), so `aocl-scalapack-sys` hand-declares them. This crate has a `Grid` (BLACS) wrapper, a `BlockCyclic` descriptor, `numroc`, and wrappers for the `gesv`, `gemm`, `potrf`, `getrf`, `getrs`, `potrs`, `syev`, `gels` and `geqrf` routines in real single (`ps*`) and double (`pd*`) precision only; the only complex wrappers are `pcgesv` and `pzgesv`. Tests: `numroc` (no MPI needed) and `tests/pdgesv_mpi.rs`, which builds a grid and solves an asymmetric 6x6 system with `pdgesv` and checks `pdgemm` (`N` and `T`) against a serial product, solves with `pdgetrf`+`pdgetrs` (`N`, `T`) `pdpotrf`+`pdpotrs` (both triangles), `pdsyev` (eigenvalues, unit-norm orthogonal eigenvectors, `A z = w z`) and `pdgels` (and `pdgeqrf`, `|R|` against a serial QR); `tests/psgesv_mpi.rs` is its single-precision twin and `tests/complex_mpi.rs` runs `pcgesv` and `pzgesv`; each on one rank under `cargo test` and on 1, 2 and 3 ranks under `mpiexec`; it was run by hand on Windows with AOCL 5.3.x and Intel MPI 2021.18, and CI runs it only on the self-hosted runner (`.github/workflows/selfhosted.yml`, dispatch-only, never yet run there). On Windows, loading AOCL 5.3.x `scalapack.dll` also needs Intel MPI (`impi.dll`), the Intel Fortran runtime, and AOCL BLIS, libFLAME and utils DLLs on `PATH`.

Built on top of [`aocl-scalapack-sys`](../aocl-scalapack-sys/).
