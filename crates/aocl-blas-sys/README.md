# aocl-blas-sys

Raw `unsafe extern "C"` bindings to AOCL-BLAS (BLIS), generated by `bindgen` at build time.

For a safe, idiomatic API on top of these bindings see [`aocl-blas`](../aocl-blas/).

## Build requirements

- An AOCL install. Set `AOCL_ROOT` if it is not at the OS-default location.
- `libclang` (used by `bindgen`). On Windows, install LLVM and ensure `libclang.dll` is at `C:\Program Files\LLVM\bin\` or set `LIBCLANG_PATH` explicitly.

## Cargo features

| Feature | Effect |
|---------|--------|
| `ilp64`       | Use 64-bit integer indexing (`ILP64/`) instead of the default 32-bit (`LP64/`). |
| `static-link` | Link against the static AOCL libraries instead of the DLL imports. |

**Measured gates (AOCL 6.0.68 Windows, LP64 and ILP64 identical; Linux unmeasured).** Of the 5704 declared functions, 2476 did not link in a dynamic build. (1) 2392 exist ONLY in the static library (`bli_*` BLIS native API, `lpgemm_*`, `lpgemv_*`, `packa_*`/`packb_*`, `bla_*`, the `AOCL_FAL_*`/`aocl_*` helpers: the 13 `AOCL_FAL_*`/`AOCL_FLIST_*`/`AOCL_get*` helpers are also exported by `scalapack.dll`: see the feature `scalapack-fal` below): they are declared ONLY with the feature `static-link` (or, for those 13, in a dynamic build with `scalapack-fal`) (a dynamic build can no longer reach them; before, a link error). (2) 83 are exported by NO installed library, dynamic or static (ARM/A64FX cpuid probes, internal `*_ref_var*`/`*_blk_var*` kernels, `*_zen4_asm_*` micro-kernels, `xerbla_array_blis_impl`, ...): left out unless the feature `header-only-unexported` (default OFF), which only declares them; it does not make them link on Windows. (3) `xerbla_array_` is exported by the libflame DLL, not BLIS: declared only with the feature `libflame` (default OFF), which links `AOCL-LibFlame-Win-MT-dll` (dynamic builds). (4) The 13 helpers that `scalapack.dll` also exports: declared in a dynamic build with the feature `scalapack-fal` (default OFF), which links `scalapack.dll` (**needs the ScaLAPACK DLL and its MPI runtime on `PATH`**). Measured: default (dynamic) 3228 of 3228 declared functions resolve; with `libflame` 3229; with `scalapack-fal` 3241 (+13), with both 3242. A `static-link` build also needs the OpenMP runtime (`libiomp5md`) on the link line, which this crate does not link (ROADMAP row 26); `tests/link_all.rs` checks the dynamic build.
