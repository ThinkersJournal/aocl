## Unreleased

- **BREAKING (pre-1.0: second number): `aocl-rng` `Rng::general_discrete` takes a `DiscreteReference`, not a raw `&mut [f64]` (safe-API memory safety; yank/GHSA are CireSnave's, board 526 B / 527)** (version: pm-assist to allocate). `drandgeneraldiscrete` trusts a length encoded inside its `ref` vector, which is only valid when one of the library's `drand{binomial,geometric,hypergeometric,negativebinomial,poisson}reference` routines wrote it; the old safe `general_discrete(&mut [f64], ..)` accepted any slice, so a safe call could make the library read out of bounds. Fix by construction (pm-kernels ruling, guide 6.0 `drandgeneraldiscrete` text): the new `DiscreteReference` can only be built by the safe constructors `binomial`, `geometric`, `hypergeometric`, `negative_binomial` and `poisson` (length query, allocation, fill; the library's own `info` surfaces as `Err` for an invalid parameter); `general_discrete(&mut self, &mut DiscreteReference, out)` takes only that type (no slice overload; `&mut` because the C parameter is non-const); the old slice entry survives as `unsafe fn general_discrete_raw` with its contract documented, so no caller loses anything. Red-first: a `compile_fail` doctest (a hand-built `DiscreteReference` cannot be constructed) plus tests that invalid parameters are refused, all five constructors sample, and the raw path is bit-identical to the typed path. `cargo test -p aocl-rng` passes (33 + 1 doctest); clippy `--lib --tests -D warnings` clean except the pre-existing `neg_cmp_op_on_partial_ord` (on main). Affected: every published `aocl-rng` with `general_discrete` (a call with a slice that is not a library-written reference). **Migration:** replace `let mut r = vec![..]; rng.general_discrete(&mut r, out)` by `let mut r = DiscreteReference::binomial(m, p)?; rng.general_discrete(&mut r, out)` (or `geometric`, `hypergeometric`, `negative_binomial`, `poisson`); a caller that already holds a reference vector written by the C `drand*reference` routines calls `unsafe { rng.general_discrete_raw(&mut r, out) }`. Callers: 0 hits for `general_discrete` / `aocl-rng` / `aocl_rng` in `Cargo.toml` or `*.rs` of the other 90 primary repos under `C:\Projects` at 2026-11-28 (`git grep` per repo; the same query finds aocl's own `Cargo.toml` and `crates/aocl-rng/src/lib.rs`, so it can see a hit); the only users are this repo's tests. Size: about +90 lines.
